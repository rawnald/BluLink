01 Executive Overview & Architecture

BluLink is a next-generation analytical platform designed specifically for intelligence analysts, investigators, defense operators, and data scientists. It provides an integrated environment where complex human, vehicular, infrastructural, and organizational relationships are synchronized in real-time with precise geospatial intelligence.

1.1 The Dual-Analytical Problem

Traditional intelligence workflows suffer from analytical fragmentation: network link diagrams are maintained in one tool, while geographic information is stored in another GIS platform. When an entity moves or a relationship changes, analysts are forced to update both databases manually, introducing transcription latency and error.

BluLink resolves this by establishing an instant bidirectional reactive bridge between:

  • Link Analysis Chart (Vis.Network 2D Engine): Displays entity nodes, organizational hierarchies, multi-hop relationship links, and custom grouping boundaries.
  • Geospatial Intelligence Map (Leaflet GIS Engine): Visualizes exact GPS locations, 10-figure MGRS military grid coordinates, real-time polyline relationship rays, and co-location clustering over Google Satellite and Terrain basemaps.

02 Getting Started: Authentication & Projects

Access to BluLink is protected by multi-factor identity authentication and granular project-level workspaces, ensuring data isolation between investigations.

2.1 Authentication & Account Setup

Authorized operators can authenticate using either enterprise email credentials or single-sign-on (Google OAuth):

  1. Navigate to the production workspace URL: https://blulink.pages.dev/
  2. Sign Up: Enter an authorized email address and master password. The system sends an automated 6-digit confirmation code via secure SMTP (Resend).
  3. Email Verification: Enter the 6-digit code in the verification modal to unlock workspace privileges.
  4. Google OAuth: Click "Continue with Google" for one-click single sign-on.

2.2 Project Management Dashboard

All investigations are stored as independent projects with dedicated entity tables, link graphs, container zones, and basemap configurations.

1 Create New Project

Click "New Project" on the top navigation bar. Enter a descriptive investigation title (e.g., Operation Trident - Cartel Tracking) and confirm creation.

2 Switch Projects

Click the active project dropdown to instantaneously switch between open cases. All graph positions and map bounds are auto-restored.

3 Clone Project

Duplicate an entire investigation workspace for branch analysis, hypothesis testing, or red-team exercise modeling without altering the master file.

4 Auto-Save Engine

Every change made in the workspace is throttled and committed automatically to Cloudflare D1 with local offline cache fallback.

03 The Dual-Pane Workspace Interface

The BluLink interface is engineered for high situational awareness. It eliminates window switching by presenting both logical relationship structures and physical geographic coordinates simultaneously.

3.1 Workspace Layout Anatomy

  • Left Pane — Link Analysis Canvas: Interactive node-and-edge network chart. Allows drag-and-drop entity arrangement, multi-segment link routing, container zoning, and live marquee selection.
  • Center Splitter Bar: Draggable divider allowing analysts to resize the Link Chart and Map panes to any desired ratio (e.g., 70% Map / 30% Graph for tactical tracking).
  • Right Pane — Geospatial Map: High-resolution Leaflet map displaying real-time entity markers, spiderfied clusters, link vectors, and coordinate indicators.
  • Left Sidebar: Collapsible tool drawer with 5 dedicated tabs:
    • Palette: Categorized icons ready to drag or click into the chart.
    • Inspect: Detailed profile, GPS/MGRS coordinates, and metadata of the selected entity.
    • List: Searchable tabular directory of all entities and links in the current project.
    • Settings: Map defaults, basemap selection, and visualization preferences.

04 Entity Management & Profiling

Entities represent persons, vehicles, facilities, weapons, organizations, communications, or contraband under active investigation.

Figure 4.1: BluLink Comprehensive Entity Palette with intelligence icon library.

4.1 Adding Entities to the Workspace

  • Method A (Drag & Drop): Open the Palette tab in the sidebar. Select an icon category, then click and drag the icon directly onto any desired location on the Link Chart canvas.
  • Method B (One-Click Placement): Click on any entity in the Palette or "All Entities" modal; it will be automatically instantiated at the center of the current chart view.
  • Method C (Custom Entity): Click "Add Custom Entity" to upload custom PNG/SVG/GIF icons, assign custom category tags, and input initial intelligence notes.

4.2 Selected Entity Identifier

Visual Selection Indicator (v1.2 Feature)
When an entity is selected, it displays clean solid gray corner framing brackets (┌ ┐ └ ┘) with corner handle marks positioned precisely at the four corners of the entity icon. It contains zero background fill and no full dashed border, preserving 100% icon clarity and visual focus.

4.3 Geographic & MGRS Coordinates

Every entity can be assigned physical geographic coordinates. BluLink features an embedded real-time coordinate converter supporting:

  • Decimal Degrees (GPS): Latitude (e.g., 14.599512) and Longitude (e.g., 120.984222).
  • Military Grid Reference System (MGRS): Standard NATO 10-figure grid precision (e.g., 51RUH1829414210). Typing GPS auto-computes MGRS; typing MGRS auto-computes GPS.
  • Interactive Map Picker (Pick on Map): Click the crosshair tool in the Inspector panel, then click anywhere on the satellite map to instantly snap the entity's location.

05 Relationship & Link Analysis

Links represent interpersonal communications, financial transfers, operational meetings, logistics supply chains, or familial associations between entities.

Figure 5.1: Live connection mode linking target entities with directional flow.

5.1 Creating Relationship Links

  • Quick Draw Mode: Open the Draw Tools dropdown and select Draw Link (or hold Shift and drag directly from any entity). Click and release on the destination entity or container box.
  • Two-Click Mode: In Draw Link mode, click once on the source node, then click once on the target node.

5.2 Link Attributes & Directionality

Figure 5.2: Link properties dialog for strength, style, width, and arrows.

Double-click any link line on the chart (or polyline on the map) to open the Edit Link Modal:

  • Relationship Label: Contextual text (e.g., "Satellite Phone Call (34 mins)", "Funds Transfer $50,000").
  • Link Strength: Confirmed (solid), Suspected (dashed), or Weak (dotted).
  • Directional Arrows: None (undirected association), Forward (➔), Backward (⬅), or Bidirectional (⬌).
  • Color & Stroke Width: Fully customizable color palette and stroke thickness (1px to 8px).

5.3 Multi-Segment / Polyline Routing (Diamond Corners)

To prevent messy line crossings in complex graphs, BluLink supports draggable polyline corners:

  • Add Corner: Open Draw Tools ➔ Add Corner. Click on any link segment to insert a draggable diamond handle (◆). Drag the diamond to route the connection cleanly around other clusters.
  • Delete Corner: Select Draw Tools ➔ Delete Corner and click any diamond handle (or select the diamond and press Delete).

06 Geospatial Intelligence & Mapping Engine

The right pane delivers high-performance tactical mapping powered by Leaflet GIS and Google Maps tiles.

6.1 Basemap Layers

Analysts can switch basemaps instantaneously via the map layer control:

  • Google Hybrid (Default): High-resolution satellite imagery overlaid with road vectors and place names.
  • Google Satellite: Pure satellite reconnaissance imagery for terrain and obstacle assessment.
  • Google Terrain: Topographic elevation contours, physical terrain features, and elevation relief.
  • Google Tactical: High-contrast dark tactical military HUD basemap engineered for low-light command operations. When selected, standard black relationship links automatically adapt to luminous white for maximum readability.
  • Esri Tactical: World Topographic Tactical basemap featuring high-contrast inverted contour lines, elevation relief, waterways, and military physical geography. Automatically adapts black relationship links to luminous white.

6.2 Co-Location Clustering & Spiderfy

When multiple entities share the exact same location (e.g., multiple suspects arrested in the same safehouse), BluLink prevents marker overlap by automatically engaging a radial spiderfy cluster upon click. Each entity fans out in a circle with a direct tether to the true ground coordinate.

6.3 Synchronized Geospatial Links

Whenever a relationship link exists between two entities with geographic coordinates, BluLink automatically renders a vector polyline between their map pins. The line features:

  • Exact synchronized color, thickness, and dash style matching the network chart (black links dynamically adapt to luminous white on Google Tactical and Esri Tactical basemaps).
  • Angle-Aligned Floating Text: The relationship label is dynamically rotated and positioned parallel to the vector line angle for seamless geospatial reading.

07 Grouping, Containers & Annotation Boxes

To represent jurisdictional perimeters, suspect cells, military task forces, or operational zones, BluLink provides intelligent container boxes.

7.1 Group Boxes & Text Annotations

  • Group Boxes: Boundary containers with customizable dashed/solid borders, background color fill opacity (0% to 100%), and corner title badges (e.g., "Suspect Cell Alpha", "Northern Operations Area").
  • Text Boxes: Word-wrapped multiline text placards for analytical commentary, date/time stamps, or executive summary text directly on the canvas.

7.2 Hierarchical Nesting (Boxes Inside Boxes)

Smart Depth Hierarchy (v1.2 Feature)
BluLink features a sophisticated area-based hierarchical hit-testing and rendering engine. When smaller boxes or entities are placed inside a larger container box:
  • The larger container box renders in the deepest background layer.
  • Clicking or double-clicking an inner box targets the innermost box directly. The inner box can be edited, resized, and duplicated without interference from the larger parent box.
  • Clicking on the parent box's border, header badge, or empty padding selects the parent box.

7.3 Interactive Selection Pills

When any container box is selected, three dedicated one-click action pill buttons appear immediately above its top-right corner:

  • ✎ Edit Box: Opens the modal to modify title, border width, dash style, fill color, and dimensions.
  • ⎘ Duplicate: Clones the box with identical properties and styles.
  • 🔓 Ungroup: Instantly dissolves the container box while preserving all entities and links inside intact.

08 Multi-Selection, Marquee & Batch Operations

Analyzing large datasets requires batch operations to group, move, or delete collections of entities and links simultaneously.

8.1 Multi-Selection Techniques

A Mouse Highlight Tool

Click Highlight in the chart header toolbar or sidebar. Drag anywhere across the canvas to draw a translucent highlight marquee that selects all enclosed entities, boxes, and lines.

B Direct Mouse Highlighting

Drag with the Right Mouse Button or hold Shift while dragging with the left mouse button to instantly highlight and select entities, boxes, and lines on demand.

C Shift / Ctrl + Click

Hold Shift or Ctrl while clicking on individual entities, boxes, or lines to toggle their selection state without deselecting other items.

D Select All & Clear

Press Ctrl + A to select everything in the workspace. Press Esc or click on empty canvas to deselect.

8.2 Group Moving & Dragging

When multiple entities and/or group boxes are highlighted or selected:

  • Real-Time Synchronized Dragging: Clicking and dragging any one of the highlighted entities or boxes smoothly moves all selected items together across the canvas while preserving their relative layout, spacing, and connection geometry.
  • Workspace Boundary Clamping: Multi-drag operations respect safety workspace borders, keeping all dragged nodes within visible analytical view bounds.

8.3 Unified & Cross-Project Clipboard (Ctrl+C, Ctrl+X, Ctrl+V)

Analysts can rapidly replicate or relocate multi-item graph clusters within a project or across separate investigative projects:

  • Cross-Project Copy & Paste: Highlight entities in Project A, press Ctrl + C, switch to Project B via the project dropdown, and press Ctrl + V. The clipboard persists across project switches, tab changes, and browser reloads via local storage.
  • Automatic Direct Connection to Matching Entities: When pasting entities into a project:
    • If any pasted entity has the same name as an entity already existing in the destination project, BluLink automatically establishes a Direct Link connecting them directly.
    • If the copied entities had relationships in the source project to neighboring entities whose names exist in the target project, BluLink automatically connects them directly to those existing nodes as well.
  • Cut (Ctrl+X): Copies the highlighted cluster to the clipboard and removes the entities, boxes, and associated links from the workspace with full undo snapshot protection.
  • Duplicate (Ctrl+D): Directly duplicates the active selection in a single keystroke.

8.4 Grouping (Ctrl+G)

When two or more items (entities, boxes, or links) are selected:

  • Press Ctrl + G (or open the Draw Tools dropdown and click Group Selected).
  • BluLink calculates the exact bounding box enclosing all selected items, adds standard 28px padding, and wraps them in a new Group Box automatically.

8.5 Ungrouping (Ctrl+Shift+G / Ctrl+U)

To dissolve a group box without deleting the records inside:

  • Select the Group Box (or select any entity inside it) and press Ctrl + Shift + G or Ctrl + U.
  • Alternatively, click the 🔓 Ungroup pill button above the box or in the Edit Box modal footer.
  • The container box is safely removed; all entities, icons, links, and coordinates remain completely intact.

09 History, Undo/Redo, Import & Export

9.1 Undo & Redo Architecture

BluLink records every workspace mutation into an in-memory chronological state stack:

  • Undo (Ctrl+Z): Steps back one operation (supports entity deletion, link creation, box resizing, grouping, and coordinate changes).
  • Redo (Ctrl+Y or Ctrl+Shift+Z): Re-applies the previously undone state.

9.2 Exporting Analytical Products

Completed link and geospatial charts can be exported for tactical intelligence briefings and court evidentiary presentations:

Format Output Target Recommended Operational Use
JSON Backup Raw encrypted data file Full forensic backup. Can be imported into another BluLink instance to restore 100% of the project.
High-Res PNG Raster Graphic Image Briefing slides, PowerPoint presentations, printed intelligence summaries, and operational case files.
CSV Spreadsheet Comma-Separated Values Tabular export of entity profiles, phone numbers, MGRS coordinates, and relationship matrices for Excel.

9.3 Restoring Workspace from Backup

To restore or share a project, click "Import Backup" in the project menu. Select the .json file; BluLink verifies schema integrity, updates nodes and links, recalculates MGRS grids, and mounts the workspace immediately.

11 Operational Troubleshooting & FAQs

Q1: Why does an entity not appear on the geospatial map?

Resolution: The entity must have valid geographic coordinates. Select the entity, open the Inspect tab in the sidebar, and confirm that both Latitude and Longitude are populated. You can also click Pick on Map and click the map directly to assign coordinates.

Q2: Can I edit an inner box when it is covered by a larger container box?

Resolution: Yes! BluLink v1.2 incorporates an intelligent hierarchical hit-testing engine. Simply double-click directly inside the inner box or on its border to open its edit modal. To edit the outer parent box, double-click on the parent box's title badge or outside the boundary of the inner box.

Q3: What coordinate precision does the MGRS converter support?

Resolution: BluLink includes a specialized military grid library (mgrs.min.js) that computes standard 10-figure MGRS grids, providing 1-meter ground resolution accuracy for tactical military and defense operations.

Q4: Does ungrouping a box delete the entities or relationship links inside?

Resolution: No. Ungrouping safely dissolves only the visual container boundary box. All entities, icons, links, attributes, and geospatial coordinates remain completely untouched.

Q5: How do I export a high-resolution chart without UI buttons for presentations?

Resolution: Click the Export dropdown in the top action bar and select Export Image (PNG). The system renders a clean, transparent or solid-background high-dpi canvas screenshot excluding all menus, banners, and toolbars.
